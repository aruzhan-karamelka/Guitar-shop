Project Overview
Dream&Strings is a student team project: a frontend guitar shop website
where visitors can explore guitar products, search and filter the
catalogue, manage a favourites list, learn about the shop, contact the
team through a demo form, and use a registration form.
The website was developed using HTML, CSS, JavaScript, jQuery, and Bootstrap for layout and styling.


Pages and Features

    index.html:
Home page, shop introduction, featured guitar categories, bestsellers, welcome interaction, and light/dark theme toggle.

    products.html:
Guitar catalogue, product search, category filters (All, Electric, Bass, Acoustic), result count, no-results message, and dynamic favourites list.

    about&contact.html: 
Shop information, team information, contact form, and FAQ accordion.

   registration.html:
Registration form with client-side validation and confirmation feedback.

    demo-result.html:      
Demonstration result page explaining that form actions are frontend-only


jQuery Interactions
The project uses jQuery to implement interactive features, including:
- Reading and validating user input and updating visible messages.
- Handling button and form events with jQuery event handlers.
- Toggling the website theme and updating the visual state.
- Animating FAQ answers with slide effects.
- Filtering products by search text and selected category.
- Updating the product result count and displaying a no-results
  message.
- Adding and removing favourites dynamically without reloading the
  page.
- Validating form fields and displaying feedback to the user.
The exact methods used can be reviewed in the external JavaScript file.

Technologies Used
- HTML5 --- page structure and semantic content.
- CSS3 --- website styling, layout, hover effects, and responsive
  design.
- JavaScript --- interactive behaviour and form logic.
- jQuery 3.7.1 --- event handling, DOM updates, filtering, dynamic
  content, and animations.
- Bootstrap 5.3.x --- layout and form styling on pages where it is
  included.


How to Run the Website Locally
1. Download or clone this repository.
2. Extract the project folder if it was downloaded as a ZIP archive.
3. Open the project folder.
4. Open index.html in a web browser.
For the most reliable local testing, use Visual Studio Code with the
Live Server extension and open the project through Live Server.
